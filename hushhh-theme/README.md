# HUSHHH — Shopify theme (Dawn)

Basis: het officiële gratis **Dawn**-thema van Shopify (OS 2.0), aangeleverd
als schone theme-export. Dit is de basis waarop de HUSHHH-site wordt
opgebouwd — geen custom-gebouwd thema meer, dus geen licentie- of
onderhoudsrisico's, en volledig compatibel met alle Shopify-apps en
toekomstige Dawn-updates.

## Installeren
1. Zip de map `hushhh-theme` (inhoud van deze map, niet de map zelf, in de
   root van de zip).
2. Shopify Admin → **Online Store → Themes → Add theme → Upload zip file**.
3. Klik **Customize** om te controleren.
